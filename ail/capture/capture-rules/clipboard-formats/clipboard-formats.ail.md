# Clipboard formats

What a snapshot holds, what kind of item it is, what makes two copies "the
same", and which formats are skipped, kept or written back.

```ail
node ClipboardFormats : fn   level: system
  why   Restoring a copy exactly, recognising duplicates and respecting
        password managers all hang on the same format rules.   <- CaptureRules
  what
    type ClipboardSnapshot = { Text?: text, Files: list of text, Image?: bytes, RawFormats: list of { Name: text, Data: bytes } }
      Image holds PNG bytes
    ClipboardSnapshot.Kind: ClipboardContentKind
    ClipboardSnapshot.Fingerprint: text
    ClipboardSnapshot.IsEmpty: boolean
    ClipboardFormatClassifier.IsExcludedFromHistoryAsync(names: list of text, readValue: (name: text) -> later bytes or nothing) -> later boolean
    ClipboardFormatClassifier.ShouldCapture(name: text, size: integer = 0) -> boolean
    ClipboardFormatClassifier.ShouldRestore(name: text, snapshot: ClipboardSnapshot) -> boolean
    MaxRawFormatBytes: integer = 32 MB
    examples
      Kind(Files ["/a", "/b"], Text "x") => FileCollection;  Kind(Files ["/a"]) => File
      Kind(Text "hello", Image png) => Text;  Kind(Image png) => Image
      Kind(Image png, Files ["<temp>/x.png"]) => Image          Firefox on Windows (#606)
      Kind(Text "", RawFormats [text/html]) => Text;  Kind(RawFormats [application/x-foo]) => Other
      Fingerprint(Text "a", RawFormats [text/html "<b>a</b>"]) is Fingerprint(Text "a") => true     text is compared by its text only
      Fingerprint(Files ["/a"]) is Fingerprint(Files ["/a"], Text "file:///a") => true
      Fingerprint(Image p1) is Fingerprint(Image p2) => true only when the PNG bytes are equal
      Fingerprint(Other) => hash of every raw format's name and bytes, each part prefixed with its length
      IsExcludedFromHistory(["ExcludeClipboardContentFromMonitorProcessing"]) => true            Windows
      IsExcludedFromHistory(["Clipboard Viewer Ignore"]) => true
      IsExcludedFromHistory(["CanIncludeInClipboardHistory" = int32 0]) => true;  = 1 => false
      IsExcludedFromHistory(["org.nspasteboard.ConcealedType"]) => true; also TransientType, AutoGeneratedType, com.agilebits.onepassword   macOS
      IsExcludedFromHistory(["x-kde-passwordManagerHint" = "secret"]) => true;  = "other" => false   Linux
      ShouldCapture("TARGETS") => false;  ShouldCapture("CF_ENHMETAFILE") => false;  ShouldCapture("text/html") => true
      ShouldCapture("application/x-foo", 40 MB) => false
      ShouldRestore("UTF8_STRING", snapshot with Text) => false;  ShouldRestore("image/png", snapshot with Image) => false
      ShouldRestore("text/uri-list", snapshot with Files) => false;  ShouldRestore("text/html", any) => true
      excluded content => the read returns an empty snapshot, after reading only the marker
  how
    decide text, files and the image are read through the toolkit's portable formats; everything else as raw bytes
      because the portable parts work the same on every system, and the raw bytes restore what the toolkit does not know (docs/architecture.md)
    decide the fingerprint looks only at what the user sees: the text, the file list, the image, else every raw format
      because side formats (time stamps, source links) differ between two copies of the same thing
    decide on Windows, formats named "Unknown_Format_<id>" are skipped
      because GDI-handle formats slip past the ignore list under that name and cannot be written back by name
    decide unreadable formats are skipped one by one, not the whole copy
      because "unknown, confirm with the owner"
  sources
    src/Shapeshifter.Core/Clipboard/ClipboardSnapshot.cs, ClipboardFormatClassifier.cs
    src/Shapeshifter.Desktop/Services/AvaloniaClipboardBackend.cs, ReadCoreAsync, WriteCoreAsync
    tests/Shapeshifter.EndToEnd.TargetApp/Program.cs, copy-secret (the marker per platform)
    GitHub issue #606; commits db7046f, b069ac4, 8556808
```
