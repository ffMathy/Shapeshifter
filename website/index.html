Shapeshifter

A clipboard manager for the 21st century.

Copy as many things as you like, then choose which one to paste, without losing any of them. Hold Ctrl + V and your clipboard history appears right where you are typing.

Download for Windowsx64 · .exe Other platforms

Also for Windows on Arm, macOS and Linux.

How it works

The paste shortcut you already use, held a little longer.

Shapeshifter does not change your habits. A quick Ctrl + V still pastes normally, even while you keep Ctrl held. Keep holding both and you get your whole history.

  1. Ctrl+C

    1Copy as usual

    Shapeshifter remembers what you copy, in every clipboard format: rich text, HTML, images, files and application-specific data. Each item is restored exactly when you paste it.

  2. Ctrl+V

    2Hold Ctrl + V

    Keep both keys held. After a short delay (300 ms by default) your clipboard history appears. Then keep holding Ctrl.

  3. Vor↑↓

    3Pick an item

    Press V again, or ↓, to move to an older item and ↑ to go back. ← / → switch between the items and the actions for the selected item.

  4. Ctrl

    4Release Ctrl

    The selected item is pasted, or the selected action runs. Changed your mind? Press Esc and nothing is pasted.

Features

Everything you copy, ready when you need it.

  • Every format, exactly

    Rich text, HTML, images, files and application-specific data are all kept, so an item comes back exactly as you copied it.

  • No new habits

    A tap of the paste shortcut pastes as always. Shortcuts with another modifier, like Ctrl + Shift + V, are left to the application.

  • At home on every platform

    Fluent 2 on Windows, Liquid Glass on macOS and GNOME's libadwaita on Linux. Each look follows your system accent colour.

  • Pin what matters

    Pinned items stay in your history and are kept across restarts. Turn on Remember history after restart in Settings to keep the rest too.

  • Respects your passwords

    Content that password managers mark as sensitive is never recorded.

  • Yours to tune

    From the tray icon, choose the delay before the history appears, how many items to keep, copy notifications and starting at login.

Actions

More than paste, depending on what you copied.

While the history is open, press → to see what you can do with the selected item, ↓ to choose an action and release Ctrl to run it. The actions on offer depend on what the item contains, listed here in the order the picker shows them.

  • Plain text

    Words, code, anything without formatting.

    1. Paste
    2. Paste as file
    3. Pin to clipboard

  • Formatted text

    Rich text and HTML from browsers, word processors and mail.

    1. Paste
    2. Paste as file
    3. Paste as plain text
    4. Pin to clipboard

  • Text with links

    Any text that contains one or more web addresses.

    1. Paste
    2. Paste as file
    3. Open links
    4. Pin to clipboard

  • Images

    Screenshots and images copied from apps or browsers.

    1. Paste
    2. Paste as file
    3. Upload and paste link
    4. Pin to clipboard

  • Links to images

    A web address that ends in an image, such as .png.

    1. Paste
    2. Paste as file
    3. Copy image from link
    4. Open links
    5. Pin to clipboard

  • Files and folders

    One or more files or folders copied in a file manager.

    1. Paste
    2. Copy as compressed folder
    3. Pin to clipboard

  • Anything else

    Application-specific data, restored exactly as copied.

    1. Paste
    2. Pin to clipboard

What each action does

Actions that make something new, such as a compressed folder or a downloaded image, add it to your history as well, so you can paste it again later.

Paste
Pastes the item as it was copied, with all of its formats. Always first, so releasing the key right away pastes.
Paste as file
Saves text to a .txt file, or an image to an image file, and pastes the file. Handy for chat apps and upload forms.
Paste as plain text
Pastes only the text, without fonts, colours or links.
Upload and paste link
Uploads the image to Catbox, a free image host without ads, and pastes a public link to it. Shapeshifter asks before the first upload; nothing else ever leaves your computer.
Copy as compressed folder
Copies the files and folders as one compressed (.zip) folder.
Copy image from link
Downloads the linked image and copies the image itself.
Open links
Opens the links in your browser (at most ten at once).
Pin to clipboard / Unpin
Keeps the item at the top of the history and across restarts. Choose it again to unpin.

Privacy

Your clipboard stays on your computer.

Shapeshifter does not send your clipboard data anywhere. Pinned items (and, if you turn it on, the rest of your history) are stored only on your own computer, and the code is open for anyone to check. The one exception is an image you choose to Upload and paste link: that image goes to Catbox, and Shapeshifter asks before the first upload.

Passwords are not recorded

Clipboard content that password managers mark as sensitive is skipped, using each platform's convention:

  • Windows ExcludeClipboardContentFromMonitorProcessing and CanIncludeInClipboardHistory
  • macOS org.nspasteboard.ConcealedType and related types
  • KDE x-kde-passwordManagerHint

Platform support

What you need.

Builds are self-contained: there is no .NET runtime or anything else to install first.

  • Windows 10 and 11

    x64 and Arm64

    Supported

    No special permissions needed.

  • macOS

    Apple silicon and Intel

    Supported

    Grant Accessibility access in System Settings → Privacy & Security → Accessibility. macOS requires it for any app that observes or sends keystrokes.

  • Linux on X11

    x64 and Arm64

    Supported

    Works on any X11 desktop. A system tray (StatusNotifierItem or XEmbed) is optional.

  • Linux on Wayland

    x64 and Arm64

    Limited

    Wayland does not let applications observe or send global keystrokes. Shapeshifter runs through XWayland, so the paste gesture only works while an X11 application is focused. Log in to an X11 session for full support.
